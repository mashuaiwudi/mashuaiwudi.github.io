Study 2 · Briefing

Collaborate with an experienced security agent

An AI agent is an AI system that can plan and carry out a sequence of actions on its own. Agents are used in office work, code maintenance, cybersecurity, and many other domains.

In this study, the agent will inspect archived URLs, call simulated security tools, and summarize evidence. At the key decision point, you will judge whether the site is phishing or legitimate before seeing the agent’s independent judgment.

Validated performance: The agent has been extensively evaluated in this task domain and achieved an accuracy above 90%.

Safety: Every link is inert archived text. Do not copy or visit it.
