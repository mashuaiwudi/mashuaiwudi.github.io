Experiment briefing

Work with an AI agent on a security task

An AI agent is an AI system that can plan and carry out a sequence of actions on its own, rather than only answering a single question. Agents are already used for office work, software maintenance, cybersecurity, and many other tasks.

In this study, you and a security agent will investigate suspicious website URLs together. For each URL, the agent will automatically run several information-gathering and analysis steps. It will inspect the domain, redirects, page identity, forms, and other security features, then summarize the evidence it found.

Your job is to read that evidence and give your own phishing-or-legitimate judgment at the key decision point. In the first phase, your judgment is advice: the agent will consider it carefully, but it may accept it or keep its own judgment. You will always be shown what the agent chose before and after receiving your input.

Phase 2

The agent now asks for your permission

You have just experienced an agent working autonomously: even when you gave advice, the agent could still keep its own judgment. In Phase 2, the agent must ask for your permission before it makes the key security decision.

The agent will still investigate the URL and summarize the evidence by itself. It will then show you the judgment it intends to use.

You can choose Let the agent decide, which authorizes the agent to use that original judgment. Or you can submit your own phishing-or-legitimate judgment. If you do, your judgment is binding: the agent will follow it and execute the matching security actions.
